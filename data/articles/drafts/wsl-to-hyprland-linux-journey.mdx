# From WSL to Hyprland: A Developer's Linux Journey

WSL created more problems than it solved. Having a Windows home directory and an Ubuntu home directory on the same machine was confusing. I'd have projects in VS Code in both systems, and inevitably one version would be old. It was manageable but it wasn't great.

The real turning point came when I learned SteamOS was Arch-based and that games could run as well or better on Linux. That was the nail in the coffin for Windows for me. 

## The Old MacBook Experiment

I put Linux Mint on my old MacBook and brought it back to life. With that going so well, I tried CachyOS with Plasma and that was actually just better than Windows. 

I think it's probably true that people who are less inclined to use the terminal should stick with Mint or Kubuntu or even just Ubuntu—but I personally can't work with the GNOME DE. It requires too much to be added in order to be able to customize things, and not everything makes sense to me coming from Windows. If you like it weird, hey maybe it's for you.

## Finding Home in Hyprland

Now today I'm on CachyOS—or even just Omarchy, which is basically just Arch Linux running Hyprland all configured and ready for Rails web devs. And it's pretty! 

The MacBook now has CachyOS/Hyprland and that is very similar, just with some of CachyOS defaults instead. Hyprland is still just a playground and has mostly replaced my tmux tiling, but tmux is still there just 4 characters away when I need it.

A few YouTube videos showing the current state of Hyprland sealed the deal—I wanted control over my whole computer, not just my terminal. Now Windows is just a clean-slate dual boot for the rare game with invasive anti-cheat.

## The Philosophy Shift

The more time you spend in Linux, the more you realize you can have power over what information you share. Maybe that's the way it should be.
