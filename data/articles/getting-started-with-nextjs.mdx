# Getting Started with Next.js

Next.js takes the complexity out of React application development. It simplifies the process of building web apps by handling the infrastructure and configuration that typically slow developers down. Instead of spending hours on setup and boilerplate, you can focus on what matters - creating great user experiences. This framework has transformed React development from a configuration-heavy process into a streamlined workflow that both beginners and experienced developers can appreciate.

## Why Next.js?

Next.js stands out from other React frameworks and vanilla React development for several compelling reasons:

- **Zero-Config Experience**: Next.js provides sensible defaults and built-in features like routing, image optimization, and bundling without requiring complex configuration, significantly reducing setup time compared to vanilla React apps.

- **The "All-in-One" Platform**: Unlike most alternatives, Next.js integrates all rendering strategies (SSR, SSG, ISR, CSR) in one framework, allowing developers to choose the right approach for each page rather than committing to a single rendering pattern.

- **Performance by Default**: Next.js automatically implements performance best practices like code splitting, bundling, and image optimization that would require significant additional work in other React setups.

- **Hybrid Rendering Flexibility**: Uniquely allows mixing rendering methods on a per-route basis—static pages for marketing content, server-rendered pages for dynamic data, and client-side rendering where appropriate—impossible with most alternatives.

- **Enhanced Developer Experience**: Provides instant feedback via Fast Refresh that preserves component state during edits, significantly improving development speed compared to standard React hot reloading.

- **Full-Stack Capabilities**: Eliminates the need for separate backend services for many use cases with API routes and Server Actions, allowing frontend developers to build complete applications without context switching between codebases.

- **Production Readiness**: Automatic performance optimizations, code splitting, and production enhancements make applications faster and more scalable without requiring specialized knowledge.

Next.js isn't just another framework—it's a complete platform that simplifies the development process while enhancing both developer experience and end-user performance.

## Getting Started

To start a new Next.js project with TypeScript, ESLint, and Tailwind CSS (recommended), run:

```bash
npx create-next-app@latest my-app
```

During setup, you'll be prompted with several options. Here's what each one means:

1. **Would you like to use TypeScript? › Yes**
   - TypeScript adds type safety to JavaScript, helping catch errors before your code runs
   - It provides better autocomplete and documentation in your code editor
   - Makes your code more maintainable as your project grows
   - Recommended for all new projects

2. **Would you like to use ESLint? › Yes**
   - ESLint checks your code for common mistakes and enforces consistent coding styles
   - Helps maintain code quality across your project
   - Catches potential bugs before they make it to production
   - Recommended for all projects, especially team collaborations

3. **Would you like to use Tailwind CSS? › Yes**
   - Tailwind is a utility-first CSS framework that makes styling faster and more consistent
   - Instead of writing traditional CSS, you add classes directly to your HTML/JSX
   - Provides a great set of pre-built styles while maintaining full customization control
   - Recommended for rapid development and consistent design

4. **Would you like to use the `src/` directory? › No**
   - The src/ directory is an optional way to organize your code
   - "No" keeps your project files in the root directory, which is simpler for beginners
   - You can always move files to a src/ directory later if needed
   - Either option is fine; we recommend "No" for simpler projects

5. **Would you like to use App Router? › Yes**
   - App Router is Next.js's newest and recommended routing system
   - Provides more intuitive file-based routing
   - Enables powerful features like server components and nested layouts
   - Recommended for all new projects (the older Pages Router is being phased out)

6. **Would you like to customize the default import alias (@/*)? › No**
   - Selecting "No" keeps the standard `@/*` alias (recommended)
   - This lets you write imports like `@/components/Button` instead of `../../components/Button`
   - Only choose "Yes" if you need a different alias pattern for specific project requirements

After selecting these options and the installation completes, run:
```bash
cd my-app
npm run dev
```

Visit http://localhost:3000 to see your app in action.

## Next Steps After Creating Your App

After setting up your initial Next.js application, here are some common next steps:

1. **Explore the Project Structure**:
   - `/app`: Contains your pages and components (App Router)
   - `/public`: Static assets like images and fonts
   - `/components`: Reusable UI components
   - `tsconfig.json`: TypeScript configuration
   - `tailwind.config.ts`: Tailwind CSS configuration
   - `.eslintrc.json`: ESLint configuration

2. **Add Styling**:
   Next.js supports various styling methods:
   - CSS Modules: `styles/Home.module.css`
   - Global CSS: Import in `app/layout.tsx`
   - Tailwind CSS: Already configured during setup
   - CSS-in-JS libraries like styled-components

3. **Create New Pages**:
   With the App Router, simply create a new folder with a `page.tsx` file inside the `/app` directory.

4. **Implement Server Actions**:
   Server Actions allow you to run server-side code from your client components:

   ```tsx
   // app/actions.ts
   "use server";
   
   export async function saveData(formData: FormData) {
     // Server-side code to save data
     const data = Object.fromEntries(formData);
     // Save to database
     return { success: true };
   }
   
   // app/form/page.tsx
   import { saveData } from "../actions";
   
   export default function Form() {
     return (
       <form action={saveData}>
         <input name="name" type="text" />
         <button type="submit">Save</button>
       </form>
     );
   }
   ```

5. **Fetch Data**:
   Fetch data in your pages or components with type safety:

   ```tsx
   // app/types.ts
   interface Post {
     id: number;
     title: string;
   }

   // app/posts/page.tsx
   async function getPosts(): Promise<Post[]> {
     const res = await fetch('https://api.example.com/posts');
     return res.json();
   }
   
   export default async function Posts() {
     const posts = await getPosts();
     
     return (
       <div>
         <h1>Posts</h1>
         <ul>
           {posts.map((post) => (
             <li key={post.id}>{post.title}</li>
           ))}
         </ul>
       </div>
     );
   }
   ```

6. **Deploy Your Application**:
   - [Vercel](https://vercel.com/docs): The creators of Next.js offer an optimized platform for Next.js
   - [Netlify](https://docs.netlify.com/): Provides support for Next.js applications
   - [AWS Amplify](https://docs.aws.amazon.com/amplify/): Serverless deployment for Next.js

## Alternative Starters and Templates

While create-next-app provides a solid foundation, consider these alternative starters for more specialized needs:

### T3 Stack

The [create-t3-app](https://create.t3.gg/) provides a full-stack, typesafe Next.js project scaffolding with:

```bash
npm create t3-app@latest
```

T3 Stack includes:
- Next.js
- TypeScript
- Tailwind CSS
- tRPC for typesafe API calls
- Prisma or Drizzle for database access (choose one)
- NextAuth.js for authentication

All components are optional and modular - you can choose exactly what you need for your project. The T3 Stack is built around the core axioms of being typesafe, solving specific problems, and "bleeding responsibly" with newer technologies.

### JStack

[JStack](https://github.com/upstash/jstack) by Upstash is a newer stack built on Next.js 15:

```bash
npx create-jstack-app
```

JStack features:
- Next.js 15
- Hono (for API routes and middleware)
- Tailwind CSS
- Drizzle ORM (lightweight alternative to Prisma)
- End-to-end type safety
- Optimized for performance

### Official Next.js Examples

The Next.js team maintains a collection of [official examples](https://github.com/vercel/next.js/tree/canary/examples) for different use cases:

- E-commerce
- Authentication
- CMS integration
- Internationalization
- Testing setups

Next.js continues to evolve with its latest version (15) introducing features like stable Turbopack for faster development, TypeScript configuration support, enhanced server actions security, and full React 19 compatibility.
